# 轻图 · 图片与视频处理工具

纯浏览器本地运行的图片和视频处理工具，文件不会上传到服务器。

## 功能

- 图片尺寸调整、批量处理和格式转换
- 图片目标体积压缩，优先保留清晰度与分辨率
- 聊天工具小表情生成
- 视频时间轴裁剪与多片段顺序拼接
- 视频封面截帧、上传、自定义适配和片头封面
- 视频按目标体积估算码率压缩

## 本地运行

```bash
python3 -m http.server 8080
```

浏览器打开 <http://127.0.0.1:8080/>。

## 浏览器兼容性

图片处理支持主流现代浏览器。视频处理依赖 `MediaRecorder`、Canvas 和 Web Audio，建议使用最新版 Chrome 或 Edge；视频输出统一为 WebM。视频会按实际播放速度重新编码。
